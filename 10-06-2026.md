---

## Weaknesses Identified

### Sparse Historical Coverage

Many skills lacked extensive historical observations.

Examples:

```text
LangChain
LLM
RAG
```

which naturally possess only recent adoption histories.

---

### Category-Level Salary Inheritance

Certain salary values required fallback imputation using:

```text
Sub-category Median Salary
```

This improves completeness but may reduce skill-level precision.

---

### Growth Signal Compression

Several skills shared similar growth-rate values because:

```text
Historical observations remain limited
```

for portions of the expanded universe.

This remains a future improvement area.

# Archetype Assignment Review

A review identified a weakness in the initial implementation.

Issue:

```text
Cluster ranking was manually score-driven.
```

This effectively recreated a synthetic SES.

Resolution:

```text
Interpret clusters using feature profiles
rather than manually ranking them.
```

This aligns better with the unsupervised learning philosophy of HSEP.

# Forecasting Validation

A critical issue emerged.

Historical skill names and workforce skill names exhibited substantial mismatch.

Examples:

```text
Stack Overflow Technologies
```

versus

```text
Workforce-Oriented Skills
```

This limited direct forecasting coverage.

Observed:

```text
331 historical skills
114 project skills
31 direct matches
```

As a result:

```text
Forecasting remains partially feasible
for mature technologies,
but remains challenging
for workforce-oriented composite skills.
```

## Major Learnings

* Feature quality matters more than feature quantity.

* Unsupervised archetypes provide stronger SES foundations than synthetic targets.
* Forecasting must adapt to varying historical coverage.
