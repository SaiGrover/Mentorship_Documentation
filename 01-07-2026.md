# Dataset Sanity Check and Dashboard Data Validation

## Objective

The objective of this phase was to review the datasets used in SkillLens AI and check whether the values, rankings, forecasts, KPIs, and graphs align with the current real-world skill landscape.

After the mentor dashboard review, the focus shifted toward validating the data behind the dashboard so that the frontend visuals are not only attractive, but also meaningful and reliable.

---

# Background

Previous phases focused on:

* Mentor review of the Dashboard page
* KPI and graph feedback collection
* Dashboard bug identification
* Methodology page appreciation
* Planning before and after screenshots
* Preparing improvements based on mentor suggestions

During the mentor meeting, it became clear that every KPI and graph must have a clear purpose and must be supported by sensible data.

The main goal was:

```text id="13k48d"
Check whether the datasets used in SkillLens AI are realistic, consistent, and suitable for dashboard visualization.
```

---

# Datasets Reviewed

The core datasets used in the project were reviewed for sanity and consistency.

Datasets checked:

* `industry_analytics.csv`
* `canonical_skill_demand_history.csv`
* `ses_rankings.csv`
* `forecast_results.csv`

These datasets are important because they directly support the Dashboard, Forecasts, Skill Explorer, Industry Analytics, and Recommendation sections of SkillLens AI.

---

# Sanity Check Purpose

The sanity check was done to identify whether the data makes sense in the current world.

The review focused on questions such as:

```text id="o2wjlr"
Do the top skills look realistic?

Do the risky skills make sense?

Are forecast values too high or confusing?

Are dashboard KPIs based on meaningful values?

Do industry insights match current technology trends?

Are graph values properly scaled?
```

This helped verify whether the platform’s outputs are believable and useful for users.

---

# Dashboard Data Validation

The Dashboard page depends heavily on summary values and graph data.

The following dashboard-related areas were checked:

* KPI card values
* Skill demand graphs
* Forecast trend graphs
* Skill category distribution
* High-risk skill indicators
* Growing skill indicators
* Industry-related summaries
* SES score ranges

The purpose was to ensure that dashboard visuals are supported by clean and reasonable data.

---

# Issues Identified

Several issues and improvement areas were identified during the sanity check.

Main issues included:

* Some KPI values needed clearer interpretation
* Some forecast values appeared confusing when shown as percentages
* Some graphs needed better scaling
* Some chart labels did not fully explain the insight
* Some skills needed to be checked against current industry relevance
* Some dashboard values required better formatting
* Some insights needed short explanations to avoid confusion
* Some data outputs needed to be reviewed before being shown directly to users

These issues are important because unclear or unrealistic values can reduce trust in the platform.

---

# Forecast Data Review

The forecast dataset was reviewed carefully because forecasting is one of the most important parts of SkillLens AI.

Focus areas:

* 1-year forecast values
* 2-year forecast values
* 3-year forecast values
* Forecast trend labels
* Forecast confidence values
* Forecast method outputs

The main improvement identified was that forecast values should be shown in a user-friendly way.

Instead of displaying confusing large values, the frontend should use clearer labels such as:

```text id="f4htzl"
Forecast Index
Expected Growth
Forecast Confidence
Trend Category
```

This makes the forecast section easier to understand.

---
