# 1. Human Skill Extinction Predictor

## Project Overview

The Human Skill Extinction Predictor is an AI-powered workforce intelligence platform designed to forecast the future relevance of professional skills over the next 5–10 years.

The system analyses:

- Global hiring trends
- Technological advancements
- Industry demand patterns
- Salary evolution
- Automation risks
- Learning platform activity

Using Machine Learning and NLP, the platform predicts whether a skill is:

- Growing rapidly
- Stable
- Saturated
- At risk of extinction

The project acts as a career intelligence system for students, professionals, recruiters, and organizations.

---

## Problem Statement

In the modern AI era, technology evolves faster than traditional education systems. Skills that are highly demanded today may become irrelevant within a few years.

Students and professionals often face questions like:

- Which skills should I learn?
- Which skills are future-proof?
- What technologies are declining?
- Which industries are hiring for the future?

There is currently no unified intelligent system capable of predicting long-term skill demand using real-world labour market data.

This project solves that problem using AI-driven trend forecasting and workforce analytics.

---

## Core Objectives

The platform aims to answer questions such as:

- Will Excel remain relevant in the AI era?
- Is Prompt Engineering temporary or long-term?
- Which software skills are declining fastest?
- Which emerging skills should students learn today?
- Which skills will companies hire for in 2030?
- Which skill combinations produce the highest salaries?

# 2. AI-Powered City Livability Index

## Project Overview

The AI-Powered City Livability Index is an intelligent urban analytics platform that dynamically evaluates how livable a city is using environmental, economic, social, and infrastructural indicators.

Unlike traditional static rankings, the platform continuously updates city livability scores using real-time datasets and predictive analytics.

---

## Problem Statement

Rapid urbanization has created major challenges including:

- Pollution
- Traffic congestion
- Climate stress
- Housing issues
- Infrastructure overload

Current city ranking systems fail to provide:
- Real-time analysis
- Predictive forecasting
- Personalized city recommendations

This project solves the problem using AI, GIS, satellite imagery, and predictive analytics.

---

## Core Objectives

The platform aims to answer:

- Which cities will become more livable in the future?
- How does pollution affect quality of life?
- Which city is best for students or professionals?
- Which cities are vulnerable to climate risks?
- Which regions are sustainable for long-term living?

---

## Parameters Analysed

| Environmental | Social & Economic |
|---|---|
| Air Quality | Employment Opportunities |
| Temperature | Healthcare Availability |
| Climate Conditions | Housing Affordability |
| Green Cover | Internet Infrastructure |
| Pollution | Public Transport |
| Urban Heat | Crime & Safety |
