## Geographic Spread Removal

Analysis revealed that the LinkedIn dataset contained postings primarily from:

* United States
* United Kingdom
* Canada
* Australia

As a result, most skills had identical geographic scores.

Example:

```text
Python  → 1.0
React   → 1.0
Docker  → 1.0
```

Decision:

```text
Geographic Spread
        ↓
Removed from SES
```

## Cloud Skill Mapping Fix

Detected zero values for:

```text
AWS
Azure
GCP
```

Root Cause:

```text
aws
azure
gcp
```

did not match StackOverflow values:

```text
Amazon Web Services (AWS)
Microsoft Azure
Google Cloud
```

Implemented alias-based skill normalization.

Examples:

| Dataset Value             | SES Skill |
| ------------------------- | --------- |
| Amazon Web Services (AWS) | aws       |
| Microsoft Azure           | azure     |
| Google Cloud              | gcp       |
