# Career Recommendation System Research

## Objective

The objective of this phase was to research how intelligent recommendation systems can be integrated into the Human Skill Extinction Predictor (HSEP) to move beyond skill forecasting and provide personalized career guidance.

After developing workforce intelligence, skill forecasting, industry analytics, and initial AI Career Advisor research, the focus shifted toward understanding how HSEP can recommend the right skills, learning paths, and career transitions for individual users.

This phase focused only on research and architectural understanding rather than implementation.

---

# Background

Previous phases of HSEP focused on answering:

```text
Which skills are growing?
Which skills are declining?
Which skills are future-proof?
```

However, a complete career intelligence platform should also answer:

```text
What should I learn next?

How do I reach my target career?

Which skills provide the highest future value?

How can I transition from one role to another?
```

To achieve this, recommendation system concepts were explored.

The goal was to understand how HSEP-generated intelligence can support personalized and explainable recommendations.

---

# Need for Recommendation Intelligence

Traditional recommendation systems usually depend on user interaction history.

Examples:

```text
Movies → Watch History

Shopping → Purchase History

Music → Listening Behaviour
```

However, career recommendation requires a different approach.

Career decisions depend on:

* Current Skills
* Target Role
* Industry Demand
* Skill Relationships
* Future Growth
* Market Value
* Technology Evolution

Therefore, HSEP requires a recommendation approach powered by workforce intelligence rather than popularity alone.

# Content-Based Recommendation

Content-based recommendation suggests items similar to a user's existing interests.

For HSEP:

```text
Current User Skills
        ↓
Find Related Skills
        ↓
Recommend Career-Relevant Skills
```

Example:

Input:

```text
Known Skills:

SQL
Excel
Power BI
```

Possible Recommendations:

```text
Python
Statistics
Machine Learning
Data Visualization
Data Engineering
```

Reason:

The recommended skills belong to related domains and help the user progress toward advanced career paths.

---

# Knowledge-Based Recommendation

Knowledge-based recommendation uses structured domain knowledge instead of relying only on historical user behaviour.

This approach was found highly suitable for HSEP because the project already generates workforce intelligence signals.

Recommendation factors:

```text
Skill Extinction Score

Forecast Trend

Skill Archetype

LinkedIn Demand

Salary Premium

Current Usage

Future Interest

Global Adoption

Industry Relevance
```

Example:

A skill with:

```text
High SES Score

+

Growing Forecast Trend

+

Strong Industry Demand

+

Low Risk Level
```

can be recommended as a future-proof learning option.

---

# Hybrid Recommendation Approach

A hybrid recommendation strategy was identified as the most suitable approach.

Instead of depending on a single method:

```text
User Profile
        +
Current Skills
        +
Career Goal
        +
Skill Intelligence
        +
Forecast Intelligence
        +
Industry Intelligence

                ↓

Personalized Career Recommendation
```

This combines user context with real workforce signals.

---

# Skill Gap Analysis Research

Skill gap analysis was studied as a core component of career recommendation.

Purpose:

Identify the difference between:

```text
Skills a user currently has

            vs

Skills required for a target career
```

Example:

Current Profile:

```text
SQL
Excel
Data Visualization
```

Target:

```text
Data Scientist
```

Missing Skills:

```text
Python
Statistics
Machine Learning
Deep Learning
MLOps
```

HSEP can then rank these missing skills based on future workforce value.

# Recommendation Ranking Strategy

Recommended skills should not be ranked randomly.

Ranking can combine:

| Factor           | Purpose                       |
| ---------------- | ----------------------------- |
| SES Score        | Measures future relevance     |
| Forecast Trend   | Predicts future demand        |
| Skill Archetype  | Shows workforce category      |
| Demand Score     | Measures hiring requirement   |
| Salary Premium   | Shows economic value          |
| Industry Mapping | Matches career domain         |
| Future Interest  | Measures learning momentum    |
| Risk Level       | Avoids declining technologies |

# Explanation Layer

A major research finding was that career recommendations must be explainable.

A recommendation should answer:

```text
Why this skill?

Why should I learn it now?

How future-proof is it?

What industries use it?

What is the forecast trend?
```

Example:

```text
Recommended Skill:

Python


Reason:

Python has strong workforce demand,
high adoption, positive forecast behaviour,
and strong relevance across Data Science,
AI, and Automation domains.
```

# Key Learnings

* Career recommendations require more than popularity ranking.
* Skill-gap analysis is essential for personalization.
* Hybrid recommendation systems are most suitable for HSEP.
* Existing SES and forecasting outputs can power recommendations.
* Explainability improves trust in career guidance.
* Recommendations should combine user goals with workforce intelligence.
* AI should explain recommendations rather than invent them.
