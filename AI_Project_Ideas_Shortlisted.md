# Data Science Project Problem Statements

## 1. Human Skill Extinction Predictor

### Problem Statement

An AI-powered platform that predicts which professional skills will grow, remain stable, or become obsolete over the next 5–10 years using labor market and technology trends.

### Objectives

* Identify future-proof and declining skills
* Predict long-term hiring demand
* Recommend valuable skills to learn
* Provide career transition guidance

### Data Sources

* LinkedIn Jobs
* Stack Overflow
* GitHub
* Kaggle
* Google Trends
* Salary Databases

### ML Components

* Time Series Forecasting (ARIMA, Prophet)
* NLP on Job Descriptions
* Recommendation System
* Clustering

### Key Features

* Future Skill Rankings
* Skill Obsolescence Risk Score
* Personalized Learning Roadmaps
* Career Guidance Chatbot
* Country-wise Demand Analysis

### Tech Stack

**Frontend:** Streamlit / React

**Backend:** Flask / FastAPI

**Machine Learning:** Scikit-learn, XGBoost, Prophet

**Database:** PostgreSQL / MongoDB

## 2. AI-Powered City Livability Index

### Problem Statement

An AI-driven urban analytics platform that evaluates and predicts city livability using environmental, economic, and infrastructure indicators.

### Objectives

* Measure city livability
* Predict future livability trends
* Analyze climate and pollution impacts
* Recommend suitable cities for different users

### Parameters Analyzed

* Air Quality
* Pollution
* Temperature
* Green Cover
* Housing Affordability
* Employment Opportunities
* Healthcare Availability
* Public Transport

### Data Sources

* OpenWeather API
* AQI APIs
* OpenStreetMap
* Satellite Imagery
* Government Datasets

### ML Components

* Time Series Forecasting
* Geospatial Analytics (GIS)
* Clustering
* Predictive Modeling

### Key Features

* Real-Time City Rankings
* Interactive Maps
* City Comparison Dashboard
* Future Livability Prediction
* Personalized Recommendations

### Tech Stack

**Frontend:** Streamlit / React

**Backend:** Flask / FastAPI

**Machine Learning & GIS:** Scikit-learn, XGBoost, GeoPandas

**Database:** PostgreSQL + PostGIS
