# Temporal Skill Intelligence, Skill Universe Expansion & Mentorship Review

**Date:** 08 June 2026

---

# Objective

Conduct a comprehensive review of the Human Skill Extinction Predictor (HSEP) framework following mentorship discussions, identify weaknesses in the existing approach, and define the next phase of research focused on temporal skill intelligence, skill universe expansion, and feature quality improvement.

---

# Mentorship Review Meeting

A detailed project review session was conducted to evaluate the current state of the HSEP framework.

The existing pipeline included:

* LinkedIn Demand
* Salary Premium
* Current Usage
* Future Interest
* Global Adoption Score
* Growth Intelligence

The original roadmap proposed:

```text
Feature Engineering
        ↓
XGBoost
        ↓
SHAP
        ↓
Skill Extinction Score
```

However, several limitations were identified during discussion.

---

# Key Mentor Feedback

## 1. Feature Engineering Should Continue

The original plan assumed feature engineering was largely complete.

Feedback:

```text
Do not stop feature engineering.
Improve the quality of existing features before moving to modeling.
```

Observation:

Although the framework contained multiple features, several signals were still derived from limited data sources and lacked long-term temporal context.

Decision:

```text
Feature Engineering Phase Extended
```

---

## 2. Skill Coverage Was Too Small

The original HSEP dataset contained:

```text
35 manually selected skills
```

Feedback:

```text
35 skills are not sufficient
for a workforce intelligence platform.
```

Concerns:

* Limited technology coverage
* Missing modern AI ecosystem skills
* Weak representation of emerging technologies
* Risk of biased conclusions

Decision:

Expand the skill universe using large-scale workforce data.

---

## 3. Single-Year Analysis Was Insufficient

Most workforce intelligence signals were generated using recent snapshots of data.

Feedback:

```text
Skills should be analyzed across years,
not only through current demand.
```

Observation:

The existing framework could identify current demand but could not accurately capture long-term evolution of technologies.

Decision:

Introduce temporal skill intelligence.
