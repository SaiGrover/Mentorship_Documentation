# SkillLens AI – Mentorship Research Repository

This repository documents my mentorship journey focused on building **SkillLens AI**, an AI-powered Workforce Intelligence and Career Intelligence Platform.

SkillLens AI is built on the **Human Skill Extinction Predictor (HSEP)** framework and combines workforce analytics, skill forecasting, industry intelligence, recommendation systems, RAG, and AI-assisted career guidance.

---

# Project Focus

## Human Skill Extinction Predictor (HSEP)

HSEP identifies:

* Future-Proof Skills
* Growing Skills
* Stable Skills
* High-Risk Skills
* Emerging Technologies
* Potentially Obsolete Skills

using workforce demand, salary signals, developer adoption, historical trends, clustering, forecasting, and career intelligence.
