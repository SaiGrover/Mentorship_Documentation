# Forecasting Research

Several forecasting methods were studied before implementation.

---

## Prophet

Prophet is an additive forecasting model developed by Meta for time-series forecasting.

General Form:

```text
y(t) = g(t) + s(t) + h(t) + εt
```

Where:

```text
g(t) = trend component
s(t) = seasonality component
h(t) = holiday effects
εt = error term
```

### Advantages

```text
Automatically models trend changes
Handles seasonality effectively
Minimal parameter tuning
Widely used in business forecasting
```

### Limitations Observed

```text
CmdStan runtime failures on Windows
Dependency instability
Annual data contained only 10–13 observations
No seasonality present in workforce data
Insufficient temporal granularity
```

### Decision

```text
Prophet Rejected
```

Reason:

```text
Implementation instability and limited benefit for sparse annual workforce data.
```

## ARIMA

ARIMA (AutoRegressive Integrated Moving Average) is a classical statistical forecasting model.

General Form:

```text
ARIMA(p,d,q)
```

Where:

```text
p = autoregressive order
d = differencing order
q = moving average order
```

Forecast Equation:

```text
Yt = c + φ1Yt-1 + φ2Yt-2 + ... + εt
```

### Advantages

```text
Strong theoretical foundation
Widely used forecasting technique
Effective on structured time-series data
```

### Limitations Observed

```text
Requires stationarity assumptions
Sensitive to parameter tuning
Limited historical observations
Unstable forecasts on sparse annual data
```

### Decision

```text
ARIMA Rejected
```

Reason:

```text
Forecasting complexity exceeded expected gains for available historical coverage.
```

## Holt's Trend Method

Holt's Method is an extension of Exponential Smoothing that models both level and trend.

Level Equation:

```text
Lt = αYt + (1-α)(Lt-1 + Tt-1)
```

Trend Equation:

```text
Tt = β(Lt - Lt-1) + (1-β)Tt-1
```

Forecast Equation:

```text
Ft+m = Lt + mTt
```

Where:

```text
Lt = level component
Tt = trend component
α = level smoothing factor
β = trend smoothing factor
```

### Advantages

```text
Works effectively on short time-series
Captures long-term trend behaviour
Computationally efficient
Suitable for annual workforce datasets
Produces interpretable forecasts
```

### Limitations

```text
Cannot model seasonality
Forecast quality depends on historical trend quality
Sensitive to noisy trend signals
```

### Decision

```text
Selected for skills with >=10 years history
```

Reason:

```text
Best balance between forecasting stability,
interpretability and historical coverage.
```

## Exponential Smoothing

Exponential Smoothing generates forecasts by assigning exponentially decreasing weights to older observations.

Formula:

```text
Ft+1 = αYt + (1-α)Ft
```

Where:

```text
α = smoothing parameter
Yt = current observation
Ft = previous forecast
```

### Advantages

```text
Simple and robust
Suitable for moderate historical coverage
Less sensitive to noise
Computationally efficient
```

### Decision

```text
Selected for skills with 7–9 years history
```

Reason:

```text
Provides stable forecasts when historical coverage is insufficient for long-term trend modelling.
```

## Feature-Based Projection

Traditional forecasting becomes unreliable when historical observations are extremely limited.

For emerging technologies:

```text
LangChain
LLM
RAG
```

future demand is estimated using workforce intelligence signals.

Features Used:

```text
LinkedIn Demand
Current Usage
Future Interest
Growth Rate
Global Adoption Score
```

Purpose:

```text
Estimate future workforce demand
for emerging technologies
with insufficient historical history.
```

# Final Hybrid Forecasting Strategy

```text
>=10 years
→ Holt's Trend Forecasting

7–9 years
→ Exponential Smoothing

<7 years
→ Feature-Based Projection
```

# Key Outcome

A redesigned forecasting framework was finalized after evaluating Prophet, ARIMA, Holt's Trend Method, and Exponential Smoothing. The final architecture balances statistical forecasting and workforce intelligence signals while remaining suitable for sparse annual skill-demand data.
