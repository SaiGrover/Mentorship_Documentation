# SES Formula Documentation

The Skill Extinction Score formula was reviewed to ensure that the documented version matches the current notebooks.

An older formula based on GitHub growth and Google Trends was rejected because it no longer represents the current HSEP scoring logic.

The current formula is:

```text
SES =
0.40 × Feature Intelligence
+
0.35 × Forecast Intelligence
+
0.25 × Cluster Intelligence
```

This formula combines:

* Current workforce signals
* Future forecasting behaviour
* Skill archetype intelligence

---

# Feature Intelligence Formula

The Feature Intelligence score combines six workforce intelligence signals.

```text
Feature Intelligence =
0.25 × LinkedIn Demand
+
0.20 × Salary Premium
+
0.20 × Current Usage
+
0.20 × Future Interest
+
0.10 × Global Adoption Score
+
0.05 × Growth Rate
```

Each feature is normalized between 0 and 1 before scoring.

This score represents the current workforce strength of a skill.

---

# Forecast Intelligence Formula

Forecast Intelligence adjusts forecast scores using forecast confidence.

```text
Forecast Intelligence =
Confidence × Forecast Score
+
(1 - Confidence) × 0.50
```

This means lower-confidence forecasts are moved closer to a neutral score.

The Forecast Score is calculated as:

```text
Forecast Score =
0.25 × Forecast Score 1Y
+
0.35 × Forecast Score 2Y
+
0.40 × Forecast Score 3Y
```

More weight is given to the three-year forecast because HSEP focuses on future workforce relevance.

---

# Cluster Intelligence Formula

Cluster Intelligence is based on the skill archetype discovered through K-Means clustering.

Mapping:

```text
Future-Proof → 0.90
Growing      → 0.70
Stable       → 0.50
High-Risk    → 0.30
```

The archetypes are discovered using:

```text
linkedin_demand
salary_premium
current_usage
future_interest
global_adoption_score
growth_rate
```

This allows the SES system to include unsupervised workforce pattern discovery rather than depending only on manually assigned scores.
